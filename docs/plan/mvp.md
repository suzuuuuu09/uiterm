## 目的

uitermのコンセプトに基づき、日常的な開発に利用できる最小限のターミナル環境を構築する。

CLIの自由度とGUIの利便性を両立し、軽量性・日本語環境での使いやすさ・カスタマイズ性を検証する。

## 技術要件

- TypeScript
- Tauri
- pnpm
- 既存のターミナル関連技術の利用
- macOS（Apple Silicon）への対応
- Linux（NixOS / Hyprland）への対応
- ネイティブWaylandへの対応

未確定の技術については、別途選定する。

## ターミナル

- シェルの起動・終了
- ANSI・VT制御シーケンスへの対応
- スクロールバック
- テキストの選択・コピー・ペースト
- ウィンドウサイズに応じたリサイズ
- カーソル・フォント・カラーの設定
- fish、NeovimなどのCLI・TUIの正常な動作

## ワークスペース

Window → Workspace → Tab の階層構造を採用する。

- ワークスペースの作成・削除・切り替え
- リポジトリ・作業ディレクトリの指定
- ワークスペース名の変更
- ワークスペースごとのタブ管理
- ワークスペース切り替え時のプロセス維持
- ワークスペース構成の保存・復元

## サイドバー

- ワークスペース一覧
- 選択中のワークスペースの表示
- Gitブランチの表示
- AIエージェントの状態表示
- 表示・非表示の切り替え
- 表示項目のカスタマイズ

## タブ

- タブの作成・削除・切り替え
- タブ名の変更
- タブの並べ替え
- タブごとの作業ディレクトリの管理
- ペインの水平・垂直分割
- ペイン間の移動

MVPではTerminalタブのみを実装する。

AIエージェントはTerminalタブ上で利用し、専用のAgentタブは後から検討する。

## AIエージェント

- 既存のAIエージェントCLIの利用
- 対応するエージェントの稼働状況の取得
- サイドバーへの状態表示
- 実行中のエージェントへの移動

最初はCodexを対象とし、他のエージェントへの対応を順次検討する。

独自のハーネスや専用チャットUIは実装しない。

## 日本語対応

- 日本語IMEによる入力
- 未確定文字列の表示
- 変換候補の適切な表示
- 変換中のキーバインド誤作動防止
- 全角・半角文字の幅の処理
- 日本語フォントへのフォールバック
- macOS標準IME・Fcitx5での動作確認

## カスタマイズ

TypeScriptによる設定ファイルを利用できるようにする。

### 設定項目

- シェル
- フォント
- カラーテーマ
- キーバインド
- サイドバーの表示項目

### API・ヘルパー関数

- ワークスペースの操作
- タブ・ペインの操作
- コマンドの実行
- サイドバーへの情報表示
- ユーザー独自の関数の定義・再利用
- 設定ファイルの型補完

設定値だけでなく、関数による独自の動作定義を可能にする。

## 操作インターフェース

以下の方法で主要な機能を操作できるようにする。

- GUI
- キーバインド
- CLI
- TypeScript API

操作方法ごとに処理を個別実装せず、共通のアクションを利用する。

## 軽量性

- Chromiumを同梱しない。
- 不要なランタイムや依存関係を増やさない。
- スクロールバックなどによるメモリ使用量の増加を制御する。
- 非表示のタブやワークスペースの描画処理を抑える。
- メモリ使用量・ディスク容量・起動時間を計測する。
- Ghostty・Herdrなどの既存環境と同一条件で比較する。

具体的な性能目標は試作時の計測結果をもとに決定する。

## MVPの対象外

- 内蔵ブラウザ
- AIエージェント専用チャットUI
- 独自AIハーネス
- リモート操作・接続
- プラグイン配布・管理機構
- 設定のクラウド同期
- アプリ終了後のプロセス維持・再接続
- 自動アップデート

## 完成条件

- [ ] macOSで正常に動作する。
- [ ] NixOS / Hyprlandで正常に動作する。
- [ ] 日本語入力を快適に行える。
- [ ] fish・Neovim・Codexが正常に動作する。
- [ ] 複数のワークスペースで並行して作業できる。
- [ ] タブ・ペインを自由に操作できる。
- [ ] AIエージェントの状態を把握できる。
- [ ] TypeScriptで設定・独自の動作を定義できる。
- [ ] 主要な操作をキーボードのみで完結できる。
- [ ] メモリ使用量・ディスク容量・起動時間を評価できている。
- [ ] 日常的な開発環境として利用できる。
